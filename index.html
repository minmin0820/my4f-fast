Four Gods — 4神の作り方

青龍 / SeiryuFull5P-Balanced›

役割：Momentum / Growth sleeve。

判定：10D・54D・6M_EX1・12M_EX1・24M_RAW の5つのMomentum判定を使用し、3-of-5以上でRisk-On。

保有：Risk-On時は QQQ 50% + QLD 50%、Risk-Off時は GLD 100%。

白虎 / ByakkoFrozenVIX›

役割：VIX / Crisis-response sleeve。

構成：Old VIX 15D 25% ＋ Old VIX 20D 25% ＋ New VIX 20D 50%。

3本のFrozen VIX signalを固定比率で合成し、Fast側では判定を再計算しない。

朱雀 / SuzakuTEL-3M/30M›

役割：Treasury–Equity Layered Dual Momentum sleeve。

各TEL判定：TMV > TMF → TMV。そうでなければEquity layerへ進み、TQQQ > TECL → TQQQ、それ以外は TECL。

合成：TEL-3M_RAW 50% ＋ TEL-30M_RAW 50%。

玄武 / GenbuMR-Majority-6D/11M/24M›

役割：Mean-Reversion / Stability sleeve。

判定：6D・11M_RAW・24M_RAW の3つのMR判定を使用。

Majority：3判定のうち2-of-3以上が示すTargetを採用するFrozen representative。

各familyのFrozen representativeを1本ずつ使用。運用月 t の判定は完了済みの t-1 までの情報だけで行い、月次リバランス。各神をタップすると実運用定義を展開。

KIRIN — 麒麟の作り方

  1. ERC6：直近6完了月の青龍・白虎・朱雀の月次return covarianceからERC weightを計算。3 Spear合計75%、玄武25%固定。
    青龍=0.75×wS / 白虎=0.75×wB / 朱雀=0.75×wZ / 玄武=0.25
  2. Defense A-state：Frozen A-stateがONなら玄武100%。Attack overlayは停止。OFFならERC6 normal。
  3. Attack75 overlay：A-state OFFかつFrozen Attack75 Turbo ONなら75%をTECL/TQQQ selectorへ。残り25%はERC6のnon-Seiryu sleevesへ元比率で比例配分。Turbo OFFならERC6をそのまま使用。
  4. Exact expansion＝天界：最終family allocationを各Frozen familyの実保有tickerへ展開し、Attack75 exposureを統合。ticker単位で集約・正規化したCanonical Exact KIRIN。
  5. Execution overlay＝現世：天界の最終ticker weightで10%未満を非保有 → survivorを再正規化 → 5%刻みにquantize → 合計100%。Frozen R289 Practical 10%。
