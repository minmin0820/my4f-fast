Four Gods — 4神の召喚法

青龍 / SeiryuVANGUARD — 先鋒RESEARCH ROLE Growth / FirepowerFull5P-Balanced›

Signal：LQD absolute momentum vs matched historical RF。5つの固定窓 10D / 54D / 6M_EX1 / 12M_EX1 / 24M_RAW を独立判定。

各窓：LQD return ≥ matched RF → Risk-On ／ otherwise Risk-Off
5判定 → 3-of-5 Temporal Majority

Holding：Majority Risk-On → QQQ 50% + QLD 50%。Majority Risk-Off → GLD 100%。月次判定。窓・vote threshold・QQQ/QLD比率はFrozen。

白虎 / ByakkoAEGIS — 守護RESEARCH ROLE Long-horizon Calmar / Crisis ConvexityFrozenVIX›

3 sleeves：Old VIX15D 25% + Old VIX20D 25% + New VIX20D 50%。評価phaseは Quarterly P1 = Jan/Apr/Jul/Oct。

Old15/Old20：^VIX absolute momentum vs matched RF
Risk-On → SPXL ／ Risk-Off → GLD
New20：^VIX20D gate + TQQQ vs TECL relative momentum
Risk-On → TQQQ or TECL ／ Risk-Off → GLD

Aggregation：3 sleevesの実現return/holdingを 25/25/50 で固定合成。Productionのdefensive destinationは GLD fixed。R138 GLD/XLU126DはChallengerであり、このFrozenVIX定義には混ぜない。

朱雀 / SuzakuPHOENIX — 逆境反攻RESEARCH ROLE Growth + Regime-dependent Tail RescueTEL-3M/30M›

TMV_L > TMF_L → TMV
else → TQQQ_L > TECL_L ? TQQQ : TECL

Aggregation：TEL-3M_RAW 50% + TEL-30M_RAW 50%。月末までの確定価格で判定し翌月へ。3Mと30Mで異なるassetが選ばれた場合も50/50でそのまま保持。

玄武 / GenbuANCHOR — 鎮守RESEARCH ROLE Stability / Sharpe / Portfolio QualityMR-Majority-6D/11M/24M›

Signal asset：SPXL。固定3窓 6D / 11M_RAW / 24M_RAW。各窓でSPXL trailing returnをmatched historical RFと比較。

各窓：SPXL return ≥ matched RF → Risk-Off vote
Risk-Off票 2票以上 → XLU
0〜1票 → TQQQ

Timing：週次。各週の最初の取引日に、前取引日までの情報だけで評価し、新holdingは次のclose-to-closeから有効。TQQQ = return engine / XLU = tail-risk circuit breaker。vote thresholdは2-of-3でFrozen。

各familyのFrozen representativeを1本ずつ使用。運用月 t の判定は完了済みの t-1 までの情報だけで行い、月次リバランス。各神をタップすると実運用定義を展開。

KIRIN — 麒麟の召喚法

  1. ERC6：直近6完了月の青龍・白虎・朱雀の月次return covarianceからERC weightを計算。3 Spear合計75%、玄武25%固定。
    青龍=0.75×wS / 白虎=0.75×wB / 朱雀=0.75×wZ / 玄武=0.25
  2. Defense A-state：Spear = 青龍+白虎+朱雀、Shield = 玄武。prior Spear 1M < 0 かつ prior Shield 12M > Spear 12M がFrozen A-state。ONなら 玄武 100%、Attack75は停止。OFFならERC6 normal。
  3. Attack75 overlay：A-state OFFでのみ評価。A = TLT 3M > 0、日次 ^VIX > 30 ならBrake。Inflection = XLK 1M − XLK 3M が前月より改善し、AかつBrakeなしならTurbo ON。selectorは prior month-end XLK 6M > QQQ 6M → TECL、otherwise TQQQ。Turbo ON時は選択assetへ75%、残り25%をERC6のnon-Seiryu sleevesへ元比率で比例配分。Turbo OFFはERC6のまま。
  4. Exact expansion＝天界：最終family allocationを各Frozen familyの実保有tickerへ展開し、Attack75 exposureを統合。ticker単位で集約・正規化したCanonical Exact KIRIN。
  5. Execution overlay＝現世：天界の最終ticker weightで10%未満を非保有 → survivorを再正規化 → 5%刻みにquantize → 合計100%。Frozen R289 Practical 10%。
